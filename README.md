# Архитектура компьютера и операционные системы

Мои домашние задания по курсу МИФИ «Архитектура компьютера и операционные системы», 2025–2026 учебный год. Изначально задания и решения хранились на GitLab Manytask под логином `mamik`.

## Разделы

| Папка | Тема |
| --- | --- |
| [asm](asm/) | Ассемблер |
| [sse](sse/) | SIMD и инструкции SSE |
| [memory](memory/) | Работа с памятью |
| [atomic](atomic/) | Атомарные операции |
| [fibers](fibers/) | Кооперативная многозадачность |
| [os-syscall](os-syscall/) | Операционные системы и системные вызовы |
| [fs](fs/) | Файловые системы |
| [elf](elf/) | Формат ELF |
| [bash](bash/) | Командная оболочка Bash |

В папках задач находятся исходники, условия и файлы для локальной проверки. Для сборки и запуска следует использовать инструкции и Makefile конкретной задачи.
